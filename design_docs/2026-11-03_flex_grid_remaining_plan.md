## Contracts to preserve

- Livery's generated shorthand metadata and `ComputedValues` are authoritative; Taffy supplies flex layout. `flex` handles none, factor and basis forms, unambiguous basis order and CSS-wide values/importance; three numeric tokens mean grow/shrink/basis, unitless zero is a valid basis, nonzero unitless basis is invalid, omitted basis is `0%`. `flex-flow` accepts direction/wrap in either order with omitted initials.
- CSSOM uses the same grammar with exact component validation and atomic rejection of extra/custom declarations, embedded importance, empty values and diagnostics. Computed unitless zero becomes `0px`, while omitted basis stays `0%`. Generic runtime reflection expands/reconstructs ordered longhands and keeps same-origin pending substitutions; malformed bridge output is an atomic no-op. Preserve delimiter escaping and engine-provided metadata.
- Project logical flex direction through Buckram `FlowAxes`; transpose vertical flex gaps without changing grid's separate lowering.
